# CareerAgent

CareerAgent 是一个面向中文求职场景的 AI 求职助手。它把简历管理、真实岗位搜索、岗位匹配、定制简历、投递材料和面试准备放在同一条流程里，用户不需要在多个工具之间反复整理信息。

它尤其适合寻找 Agent、LLM 应用、RAG、AI 后端等岗位，也可以用于其他技术方向。

## 能做什么

### 搜索和浏览真实岗位

- 不提供简历也可以直接搜索岗位。
- 默认同时查询国内企业官方招聘网站和系统内已保存的岗位。
- 支持按岗位方向、城市、实习或校招等条件筛选。
- 每个岗位都有独立详情页，可以查看原始 JD 和官方投递入口。

当前中文岗位源覆盖腾讯、百度、美团、字节跳动、阿里巴巴、蚂蚁集团、京东、华为、小米、OPPO、vivo、快手、哔哩哔哩、小红书、得物、大疆、网易、MiniMax、DeepSeek、月之暗面等国内企业。

### 建立简历档案

可以用三种方式准备简历：

1. 上传已有 PDF，自动解析姓名、教育、项目、实习和技能。
2. 用自然语言描述经历，由 Agent 整理成简历档案。
3. 手动填写，并自由选择需要的栏目和经历数量。

建立后的档案可以直接预览，也可以进行通用评分或结合某个岗位进行针对性评分。

### 分析岗位匹配度

选择简历后，岗位详情页会展示已满足的要求、能力缺口、支持结论的项目经历，以及后续应该优先补充或改写的内容。

匹配结论以真实简历和 JD 为依据，不会把计划学习的技能写成已经掌握。

### 生成定制简历

用户可以从岗位详情页发起定制，也可以在“定制简历”页面选择简历与岗位。

系统会优先保留与 JD 相关的真实经历，调整技能顺序和项目表达，并单独展示评分、修改建议、事实检查和改动摘要。这些检查信息不会写进简历正文。

### 准备投递材料

系统可以生成求职信、外联文案、投递检查清单和材料包。涉及真实网页填写或邮件发送时，必须先由用户确认，系统不会在后台自动替用户投递。

### 准备面试

面试包会综合目标岗位 JD、简历项目技术栈，以及同岗位面经与常见基础问题。每道题会提供可直接参考的回答、可能的追问、可引用的项目证据和练习状态。

## 三种常见用法

### 只有求职方向，没有简历

1. 打开“开始”页面。
2. 描述想找的岗位、城市和偏好技术。
3. 选择“不使用简历”。
4. 浏览搜索结果，打开感兴趣的 JD。
5. 需要匹配时再上传或新建简历。

### 只有简历，不确定适合什么岗位

1. 在“简历”页面上传 PDF。
2. 预览解析结果，确认信息是否完整。
3. 点击“用这份简历找岗位”。
4. 系统根据目标方向、技能和经历组织检索请求并排序岗位。

### 已经有简历和目标岗位

1. 打开岗位详情并选择简历。
2. 查看匹配项、能力缺口和简历评分。
3. 生成定制简历并检查修改建议。
4. 用户确认后生成投递材料。
5. 针对同一份简历和 JD 生成面试准备包。

## 快速启动

### 1. 安装依赖

建议使用 Python 3.12：

```powershell
python -m pip install -r requirements.txt
python -m playwright install chromium
```

### 2. 配置模型

复制 `.env.example` 为 `.env`，至少填写：

```env
LLM_API_KEY=你的 API Key
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-v4-flash
```

没有配置模型时，仍可浏览已有简历和岗位；PDF 智能解析、简历评分、定制简历和面试准备会明确提示不可用。

### 3. 启动网页

```powershell
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)，从“开始”页面进入完整流程。

### 4. 启用后台任务

长时间运行的岗位搜索和材料生成建议通过 Redis Worker 执行：

```powershell
redis-server
python scripts/run_agent_worker.py
```

任务进度会保存在服务端。刷新页面或切换到其他页面后，仍可从右下角状态卡或“历史记录”继续查看和处理。

## 页面说明

| 页面 | 用途 |
| --- | --- |
| 开始 | 输入求职方向，选择是否使用简历并搜索岗位 |
| 简历 | 上传、创建、预览和评分简历档案 |
| 岗位 | 搜索岗位并浏览完整 JD |
| 定制简历 | 根据指定简历和岗位生成简历版本 |
| 投递 | 查看投递材料与需要确认的操作 |
| 面试 | 生成并练习岗位针对性面试题 |
| 历史记录 | 查看最近任务、运行进度和待确认事项 |
| 控制台 | 查看队列、审批、运行健康和模型用量 |

## 使用边界

- 招聘网站随时可能调整页面或接口。系统会把来源异常明确记录下来，不会用虚构岗位补齐结果。
- 简历定制只改写用户已经提供的事实，不会编造项目、指标或工作经历。
- 岗位匹配和简历评分用于辅助判断，不能替代用户对 JD 和简历内容的最终确认。
- 浏览器投递和邮件发送属于高风险操作，必须经过独立审批。
- 简历包含个人信息。正式部署时应开启登录、租户隔离、HTTPS、数据库备份和访问审计。

## 技术组成

CareerAgent 使用 FastAPI、LangGraph、SQLite、Redis、Playwright、向量检索和 Reranker 构建。任务状态、检查点、工具调用、审批和运行事件都会持久化，便于恢复、审计和排查问题。

本项目仍应在真实使用中持续校准岗位源、RAG 检索和生成质量。控制台与评测工具用于维护这些能力，但不会干扰普通用户的求职页面。
