Outbound smoke

外发工具端到端 Smoke

控制台
浏览器辅助填写 targetlocal

用 browser_apply 填写本地页面，不依赖外部招聘站。

{
  "url": "http://127.0.0.1:8000/ui/outbound-smoke/target",
  "fields": {
    "#full_name": "李明",
    "#email": "liming@example.com",
    "#message": "申请 Agent 开发实习岗位"
  }
}
打开 target
邮件草稿/发送 payloadSMTP
{
  "to": "hr@example.com",
  "subject": "Agent 开发实习申请",
  "body": "您好，我想申请 Agent 开发实习岗位，附件为我的简历。"
}

`email_draft` 会输出 `.eml`；`email_send` 需要 SMTP_HOST 等环境变量，可配合本地 Mailpit 容器验证。

Runbook

运行顺序

  1. 创建一个 Agent run。
  2. 调用 `/ops/high-risk-actions/request` 创建 `browser_apply`、`email_draft` 或 `email_send` approval。
  3. 在控制台审批通过。
  4. 调用 `/ops/high-risk-actions/{approval_id}/execute`，观察 artifact 和审计事件。
